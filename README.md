# Игровая платформа-трекер (Микросервисы)

Учебный проект: микросервисная система для отслеживания игровой активности (что-то вроде легкого аналога Steam). Платформа позволяет пользователям добавлять игры в библиотеку, трекать свои игровые сессии и получать очки, на основе которых строятся глобальные лидерборды.

## Технологический стек
* Бэкенд: C# (.NET)
* База данных: PostgreSQL
* Взаимодействие: REST API для внешних клиентов, gRPC для общения сервисов между собой
* Инфраструктура: Docker, Docker Compose

## Структура проекта
Исходя из требований к размеру команды (3 человека = 2 сервиса), мы физически делим систему на два микросервиса, объединяя смежные доменные области:
1. User & Catalog Service: берет на себя управление пользователями, аутентификацию, общий каталог игр и личные библиотеки.
2. Tracking Service: отвечает за учет игровых сессий, тайминги, начисление очков и генерацию рейтингов.
